# ASA Directory of Statistical Consultants

This is a Quarto website for the ASA Directory of Statistical Consultants. The website went live on 9/8/2026. 

## Updating the Directory

- Review the Google Form submissions. Sometimes ASA numbers need cleaning.
- Locally, build the quarto website
- Check for issues on the GitHub page, resolve any outstanding issues if possible.

## Annual maintenance process

Annually, the main step is to delist non-Section members, which requires new data from the ASA (from https://ww2.amstat.org/OfficerReports/index.cfm, available on leadership hub)
